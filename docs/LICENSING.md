# WICOFE Licensing Policy

## 1. Project license

Original source code contributed to WICOFE is licensed under the Mozilla Public License 2.0 (MPL-2.0), unless a file or directory explicitly states otherwise.

The complete license text is in the repository root at [LICENSE](../LICENSE).

## 2. Dependency policy

For Alternative The project policy is not to integrate GPL-, LGPL-, or AGPL-licensed code or dependencies.

Permissive licenses such as MIT, ISC, BSD-2-Clause, BSD-3-Clause, and Apache-2.0 may be considered after review. Approval is not automatic.

## 3. Third-party material

Third-party code retains its original license. Inclusion in this repository does not relicense that code under MPL-2.0.

Before integration, record:
- Project and exact version/revision.
- Source URL and provenance.
- License identifier and license text.
- Required copyright and attribution notices.
- Patent and redistribution conditions.
- Whether modifications are made.
- Compatibility with the WICOFE distribution policy.

Do not copy code from a project merely because its functionality is useful. Review the actual source and license of every imported component.

## 4. Notices and compliance

Preserve required copyright, license, patent, and attribution notices. Add third-party notices when required.

CI should eventually run dependency and source-license auditing. Any ambiguous, custom, dual, or missing license must be reviewed before acceptance.

## 5. Scope

This policy describes the project's intended contribution and dependency rules. It is not legal advice and does not replace review of the applicable license texts.
